NJH 補聴器 ご注文書 作成アプリ

■ 収録様式（全14種類）
Unitron：
・Moxi S-R
・Moxi Vivante R / 312 / RS
・Stride V-PR
・Stride V-SP / UP
・Moxi Blu R / 312

Beltone：
・Envision 62S / 64DW
・Envision クロス送信機
・Commence 62 / 64DW
・Serene 62S / 63DW
・Serene 76 / 86 DW
・Rely RIC
・Rely BTE
・Boost Max S
・Boost Ultra

■ 主な機能
・スマートフォン向けの段階式入力
・左右別のカラー／レシーバー／耳せん等の選択
・NJH原本画像を背景にしたA4注文書プレビュー
・PDF保存、画像保存、印刷／FAX、メール・LINE共有
・店舗情報と担当者情報の端末内保存
・オフライン用キャッシュ（全14様式）

■ 公開方法
このフォルダー内の index.html、img フォルダー、manifest.webmanifest、sw.js、アイコンをまとめて静的サイトとして公開してください。
Netlifyで既存サイトを更新する場合は、展開後の「NJH注文書」フォルダーの中身を新しいデプロイとしてアップロードします。

■ データの取り扱い
注文入力・PDF生成はブラウザー内で処理します。店舗情報は使用端末のブラウザー内に保存されます。お客様情報はアプリ内に保存しません。作成したPDF／画像は利用者が保存・共有してください。

■ 注意
この版は提供された注文書画像と選択項目に基づく実装です。実際のFAX送信に使う前に、各機種でテスト注文を作成し、チェック位置・記載内容・A4印刷結果を原本と照合してください。
